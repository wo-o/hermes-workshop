# 회의록 실행 항목 추출

회의 내용을 단순히 요약하지 않고 결정 사항, 실행 항목, 확인 필요 사항으로 분리합니다. 원문에 없는 담당자나 기한은 추측하지 않습니다.

## 사용 시점

- 회의록에서 담당자와 후속 작업을 정리할 때
- 결정된 내용과 제안만 나온 내용을 구분해야 할 때
- 사용자가 단순 요약만 원한다면 이 스킬을 사용하지 않습니다.

## 입력

회의록의 본문 또는 회의록 파일 경로가 필요합니다. 파일 경로가 주어지면 `read_file`로 원문을 읽습니다.

## 절차

1. 참석자, 날짜, 안건을 원문에서 확인합니다. 찾을 수 없는 항목은 `미기재`로 둡니다.
2. 명시적으로 합의된 문장만 결정 사항으로 분류합니다.
3. 행동, 담당자, 기한이 연결된 문장을 실행 항목으로 추출합니다.
4. 담당자나 기한이 없으면 값을 만들지 말고 `확인 필요`로 표시합니다.
5. 이견, 보류, 추가 질문은 미결정 사항으로 분리합니다.
6. 각 항목에 짧은 원문 근거를 붙여 추적 가능하게 만듭니다.

## 출력 형식

```text
회의 개요
- 날짜:
- 참석자:
- 안건:

결정 사항
- 결정 — 근거: "원문"

실행 항목
| 작업 | 담당자 | 기한 | 상태 | 근거 |

확인 필요
- 질문 — 부족한 정보
```

항목이 없으면 섹션을 생략하지 말고 `없음`이라고 표시합니다.

## 주의 사항

- 제안, 희망, 검토 예정 표현을 확정된 결정으로 바꾸지 않습니다.
- 상대 날짜는 회의 날짜가 있을 때만 절대 날짜로 변환합니다.
- 개인정보나 비밀 값은 출력에 반복하지 않습니다.

## 검증

- 모든 실행 항목이 원문 근거를 가집니다.
- 원문에 없는 담당자와 기한이 생성되지 않았습니다.
- 결정 사항과 확인 필요 사항이 분리되어 있습니다.
